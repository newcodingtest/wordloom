# 07. 자동·통합·PWA 수락 테스트 (실제 내장 6,000개 필수)

## 원칙

- **테스트 fixture 6,000개는 성능 시험 전용**이며 내장 콘텐츠 수량 증빙으로 인정하지 않는다.
- 검증 대상은 반드시 **실제 배포될 `data/catalog-manifest.json`과 모든 `data/packs/*.json`의 합본**이어야 한다.
- 단순 UI에 '6,000'이라고 적힌 것은 검증 증거가 아니다. 실제 저장된 데이터와 동일한지 확인한다.
- 각 테스트는 실행 방법·성공 기준·결과를 README나 리포트에 남긴다. 실행하지 않은 테스트는 통과로 표시하지 않는다.

## 실제 브라우저 통합 테스트

### A. 첫 방문/6,000개 로딩

- [ ] **신규 브라우저 프로필**에서 앱 처음 열면 수동 import 없이 내장 팩을 자동 다운로드·저장한다.
- [ ] 로딩 중 진행/오류를 분명히 표시하고 모든 팩 완료 전 설치 완료로 오인하지 않는다.
- [ ] 완료 후 IndexedDB `words` store의 실제 고유 표제어 수가 **6,000개 이상**이다.
- [ ] UI 홈/단어장 총계와 IndexedDB 실제 카운트가 일치한다.
- [ ] 첫 100개만이 아니라 목록 중간·마지막·여러 주제의 실제 데이터가 검색·카드 학습 가능하다.
- [ ] 새로고침 후 전체 단어 수가 유지되고 진도/즐겨찾기 초기화 없음.
- [ ] `app.js`/manifest/팩 요청에 404와 콘솔 오류가 없다.

### B. 카드·10문제 시험·복습

- [ ] 영어 앞면↔한국어 뒤면, 클릭·터치·Enter·Space 반전.
- [ ] 4가지 평가 저장, 복습 시점 계산, 페이지 이동 뒤 진도 유지.
- [ ] 실제 내장 어휘에서 정확히 10문항과 정답 중복 없는 4개 보기 생성.
- [ ] 시험 결과/오답·복습 연동, 퀴즈 정답만으로 mastered 변경 금지.
- [ ] 전체 목록에서 서로 다른 레벨·카테고리의 임의 단어 30개 샘플 카드로 접근.

### C. 검색·통계·백업

- [ ] 영문/한국어 검색, 레벨/카테고리/상태 필터가 실제 6,000개에 적용됨.
- [ ] 페이지네이션/가상화, 모바일 입력 속도와 스크롤 동작 확인.
- [ ] 통계에 총 어휘 수와 학습한 고유 표제어 수가 구별되어 표시됨.
- [ ] 백업·복원 후 **기본 제공 전량 + 사용자 학습 진도**가 복구됨.
- [ ] 콘텐츠 업데이트·앱 재시작 뒤 북마크/SRS/오답 보존.

### D. 설치·오프라인 6,000개 전체

- [ ] HTTPS 또는 localhost에서 manifest/서비스 워커 등록 정상.
- [ ] 첫 온라인 접속 후 전체 팩 다운로드 완료 여부가 확인됨.
- [ ] **네트워크를 완전히 끈 후** 앱을 종료하고 다시 열어 6,000개 단어 수 확인.
- [ ] 오프라인에서 목록 첫 단어·중간·마지막 단어를 각각 검색·카드 뒤집기 가능.
- [ ] 오프라인에서 전체 어휘 시험 10개 출제/채점 및 진도 저장 가능.
- [ ] SW 업데이트/새 코드 배포 후 IndexedDB 진도 보존.
- [ ] Android 설치 및 iOS 홈 화면 추가(확인 가능한 실제 기기별로 기록).

## 데이터·런타임 장애 시험

- 팩 중 하나가 404인 최초 방문 → 미완성 상태 표시와 재시도; 6,000개 완료로 속이지 않음.
- 브라우저 저장 용량 부족/IndexedDB 사용 불가 → 데이터 손실 방지 및 명확한 오류.
- 저장된 팩 버전과 manifest 버전 불일치 → 업데이트/복구 경로.
- 이전 v1 DB의 590개 및 학습 기록 → 6,000+개로 마이그레이션 후 기존 590개 진도 유지.
- 실제 6,000개를 사용한 연속 필터/검색, 다중 탭, SW 갱신 경쟁 조건.
- 동의 없는 외부 원격 어휘 API 호출이 없는지 네트워크 탭으로 확인.

## 최종 P0 판정

**전부 충족해야 출시 가능:** 7개 화면 + 진짜 기본 내장 영어↔한국어 6,000개 이상 + 출처/라이선스 기록 + 스키마/중복/뜻 검증 + 진도 영속성 + 시험·SRS + 백업 + 설치·오프라인 전량 사용 + 자동/실기기 테스트.

불가능한 항목은 **미완료**로 명시하고 출시 가능 판정을 보류한다. 콘텐츠는 이후 P1 작업으로 연기할 수 없다.
