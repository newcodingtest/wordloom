# 01. 제품 요구사항 (PRD)

## 목표와 사용자

- 사용자: 영어 기초부터 TOEFL 어휘 학습을 시작하고 싶은 한국어 사용자. 자격증 점수를 올리면서 꾸준히 학습하는 습관을 만들고 싶다.
- 목표: **실제 한국어 뜻과 출처가 검증된 TOEFL 학습용 고유 표제어 6,000개 이상을 기본 탑재한** 학습 웹앱. 사용자가 별도 파일을 업로드하지 않아도 카드/시험/검색에 전량 접근할 수 있어야 한다.
- 학습 루프: 오늘 할 일 확인 → 카드 뒤집기 → 스스로 평가 → 10문항 객관식 → 오답 즉시 확인 → 복습 예정일 관리.
- PWA와 오프라인 퍼스트, 작은 화면에서 한 손 사용에 적합한 조작.

## 정보 구조와 내비게이션

| 라우트 | 화면 | 핵심 행동 | MVP |
|---|---|---|---|
| `#home` | 홈 | 오늘 신규/복습 진도 확인, 이어하기 | 필수 |
| `#cards` | 암기 카드 | 표제어⇄뜻, 음성, 평가, 즐겨찾기 | 필수 |
| `#quiz` | 10문제 시험 | 학습 범위 선택, 10개 4지선다, 채점 | 필수 |
| `#words` | 단어장 | 검색, 난이도/상태/카테고리 필터 | 필수 |
| `#review` | 오답·기한 복습 | 틀린 단어, 복습 기한 경과 단어 재학습 | 필수 |
| `#stats` | 학습 통계 | 누적 학습, 7일 기록, 정답률 등 | 필수 |
| `#settings` | 설정 | 목표, 음성, 데이터 백업/가져오기 | 필수 |

모바일 하단 탭에 모든 화면을 무리하게 넣지 않는다. 주요 4~5개를 우선 노출하고 나머지는 메뉴에서 접근할 수 있어야 한다.

## 주요 흐름

### F1. 첫 방문/온보딩

1. 앱 첫 실행 시 `data/catalog-manifest.json`을 읽고 **배포에 실제 포함된 내장 단어 팩 전량(6,000개 이상)**을 파싱·검증해 IndexedDB에 자동 삽입. 실패 시 진행/오류/재시도 경로 제공.
2. 최초 기본 목표: 신규 20개/일, 카드 복습 20개/일(사용자가 조정). 목표는 단어 총량과 별개.
3. 첫 데이터 로드 완료 후 홈 화면. 빈 데이터·오프라인 초기 방문 시 안내 및 재시도.
4. **590개 샘플로 릴리스 불가.** 홈/단어장에는 실제 설치된 유효 고유 단어 수(기본 6,000개 이상)를 조회해 표기하며, 사용자가 가져온 단어와 기본 제공 단어를 필요시 구분한다.

### F2. 카드 학습

1. 공부할 덱: `오늘 학습`(기한 복습 우선+오늘 신규), `오답`, `즐겨찾기`, `전체`, 카테고리/난이도.
2. 영어 카드 앞면을 기본으로 보여준다. 탭/클릭/Enter/Space로 카드 뒤집기 → 한국어 뜻과 예문(있는 경우) 표시.
3. 뜻 확인 후에만 `다시`, `어려움`, `알겠음`, `쉬움` 선택 가능(강제 해금 또는 적어도 명확한 안내).
4. 평가 저장 후 다음 카드. 나중에 앱을 열어도 평가/다음 복습일 유지.
5. 발음 버튼은 영어 발음 재생. 음성합성 지원이 없을 때 오해 없이 안내.

### F3. 10문제 시험

1. 학습 범위 선택: 오늘 학습한 단어, 복습/오답, 전체 중 선택. 기본값은 학습 기록이 있으면 최근 학습, 없으면 전체.
2. 서로 다른 영어 표제어 **정확히 10개**, 각 문제에 한국어 뜻 **4지선다**, 정답은 1개. 보기도 의미가 서로 구별되도록 중복 제거.
3. 정답 선택 시 확인 피드백을 주되 이후 선택 변경은 못한다. 다음 문제 진행.
4. 마지막에 `X/10`, 정확도, 틀린 항목과 정답 노출. 다시 풀기/오답 카드 복습 연결.
5. 틀린 단어는 오답 큐로 지정하여 재학습 대상으로 올라온다. 객관식 정답만으로 '완전 암기' 처리하지 않는다.
6. 후보 단어가 10개 미만 또는 고유 오답 뜻이 부족할 때 문제를 임의 복제하거나 정답을 노출하지 말고 안내/덱 변경 기능 제공.

### F4. 단어장

- 표제어, 한국어 뜻 검색, 레벨(1~4 또는 확장), 카테고리, `미학습/학습 중/복습 필요/암기 완료`, 북마크 필터.
- 적어도 한 번에 수천 행을 DOM에 모두 렌더링하지 않을 것(페이지 분할 또는 가상 스크롤).
- 각 항목에서 카드 열기, 발음, 북마크 토글 가능.

### F5. 오답 및 SRS 복습

- 카드 자기 평가 기반의 복습 시각(dueAt)과 퀴즈 오답 큐를 분리 보존한다.
- `오늘 복습` = 복습 예정시각 도달 + 미해결 퀴즈 오답(중복 하나로 통합).
- 복습 완료 직후 결과가 통계와 대시보드에 반영된다.

### F6. 통계

- 실제로 설치된 유효 고유 단어 수(기본 6,000개 이상), 확인한 단어 수, 학습 중 수, 암기 완료 수, 오늘 신규 평가 개수, 오늘 복습 개수, 현재 복습 대기, 퀴즈 누적 정답률, 최근 7일 학습 기록.
- 동일 카드의 반복 조회는 `학습 완료 건수`를 부풀리지 않는다. 상태 정의는 `docs/05_LEARNING_ALGORITHMS.md`를 따른다.

### F7. 설정과 데이터 보호

- 신규 목표/복습 목표/음성 속도 변경.
- 모든 단어(기본 제공 6,000개 이상+사용자 import), 학습 진도, 시험 이력, 설정을 JSON으로 백업.
- 복원에는 형식 검증·미리보기·명시적 확인(병합 또는 교체)이 필요. 잘못된 JSON으로 기존 데이터를 지우면 안 된다.
- 데이터 전체 초기화에는 경고 및 별도 확인 절차.
- 서버 계정/자동 동기화는 초기 버전 범위 밖임을 고지.

## 비기능 요구사항

- 모바일: 최소 폭 320px 대응, 세이프 에어리어, 다크/라이트 브라우저에서도 가독성, 터치 상호작용 지원.
- 접근성: 정보 전달에 색상만 의존하지 않기, 버튼 레이블, 논리적 포커스 순서, 스크린리더에 카드 앞/뒤 상태 전달.
- 오프라인: **최초 전체 내장 팩 로드/시딩 완료 후** 앱 셸과 기본 제공 6,000개 단어 전량의 읽기·카드·시험·학습 기록 저장을 지원한다.
- 데이터 성능: **실제 배포 6,000개 이상 데이터**를 기준으로 검색/필터 사용성과 최초 로드 성능을 테스트한다.
- 개인 정보: 최초 버전은 사용자 학습 정보의 외부 전송 없음. 분석 SDK/광고 SDK 미도입.
- 퀄리티: 한국어 뜻의 부정확함이나 영어 단어 중복은 학습 신뢰를 해치므로 명시적 검증 파이프라인 제공.

## 범위 밖 (향후 후보)

- 서버 기반 기기 간 동기화/로그인, 웹 푸시, 리더보드, AI 문장 교정, 실제 TOEFL 모의고사, 결제.
- 'TOEFL 공식 출제 6,000개'라는 근거 없는 표현 금지: **학습 목적 자체 큐레이션 어휘**로 명명한다.

## 콘텐츠 출고 조건 (P0 필수)

- 실제 배포에 포함된 영어↔한국어 단어 팩의 고유 표제어가 **최소 6,000개**일 것. 590개 샘플을 향후 확장 과제로 넘기지 않는다.
- 첫 실행 시 자동 설치, 재실행 후 실제 개수 유지, 오프라인에서 전량 사용.
- `docs/03_VOCABULARY_DATA.md`, `docs/07_TEST_ACCEPTANCE.md`, `docs/08_6000_WORD_RELEASE_GATE.md`의 검사 및 수락 조건 통과.
- 데이터 미달·라이선스 미확인·뜻 품질 미검증이면 출시 완료 불가.
